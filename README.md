# 🧺 Kasir-Laundry - Sistem Manajemen Laundry

Kasir-Laundry merupakan aplikasi berbasis web yang dikembangkan menggunakan Laravel dan MySQL untuk membantu pengelolaan operasional bisnis laundry secara lebih mudah, terstruktur, dan efisien.

Aplikasi ini dilengkapi dashboard untuk memantau aktivitas laundry serta fitur pengelolaan data menggunakan sistem CRUD (Create, Read, Update, Delete).

## ✨ Fitur Utama

- **Dashboard** – Menampilkan ringkasan data konsumen, barang, supplier, transaksi, dan total pendapatan.
- **Manajemen Konsumen** – Mengelola data konsumen.
- **Manajemen Barang** – Mengelola data barang laundry.
- **Manajemen Supplier** – Mengelola informasi supplier.
- **Manajemen Tarif** – Mengelola tarif layanan laundry.
- **Manajemen Transaksi** – Mencatat dan mengelola transaksi laundry.

## 🎨 Tampilan Aplikasi

Kasir-Laundry menggunakan desain antarmuka modern dengan kombinasi warna soft teal, putih, dan abu-abu. Tampilan dibuat sederhana, responsif, dan mudah digunakan.
